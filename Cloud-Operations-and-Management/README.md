# Cloud Operations and Management  

This module covered cloud computing from its foundations to emerging trends:
service and deployment models, cloud architecture frameworks and Infrastructure
as Code, cloud-native tools, hybrid, fog and edge computing, security and
compliance, disaster recovery and business continuity, cloud migration,
serverless computing, AI in cloud operations, and future trends such as
quantum computing. The final artefact is a reflective e-portfolio that brings
these topics together.
