# Advanced Object-Oriented Design and Programming

This module covered advanced object-oriented design and programming in Python:
SOLID principles, creational, structural and behavioural design patterns,
concurrency and thread safety, refactoring and code smells, secure coding
practices, and Test-Driven Development. The final artefact is a thread-safe
banking program that brings all of these together.
