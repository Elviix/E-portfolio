# Unit 12: Capstone Project and Review

## Context
Unit 12 was the culmination of the module: finalising the capstone project, which had to demonstrate OO principles, 
design patterns and secure coding practices, and reviewing all the key concepts covered since Unit 1.

## My work and reflection
My capstone is the thread-safe banking program presented in Task 2, which brings together everything from the module: encapsulation and polymorphism from Unit 1, 
SOLID from Unit 2, the Command, Decorator and Visitor patterns from Units 4 and 5, thread safety and deadlock prevention from Unit 6, refactoring from Unit 8, 
and testing with mocks from Unit 10. The full code and its critical commentary are in the Artefacts section [End of module assignment code.py](https://github.com/Elviix/E-portfolio/blob/main/Advanced-Object-Oriented-Design-and-Programming/Artefacts/Individual-project/End-of-module-assignment-code.py) and [End-of-module-assignment.pdf](Advanced-Object-Oriented-Design-and-Programming/Artefacts/Individual-project/End-of-module-assignment.pdf).
Preparing the review made me realise how much the units build on each other: the final program only works because each concept was added on top of a structure the previous units had made solid.
