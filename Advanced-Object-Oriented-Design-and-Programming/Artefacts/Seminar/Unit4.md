# Unit 4: Structural Design Patterns

## Context
Unit 4 covered the structural design patterns, Adapter, Bridge, Composite, Decorator, Facade, Proxy and Flyweight, which organise classes and objects into larger, more flexible structures. The practical work for this unit was a collaborative discussion where we produced Python examples of the Adapter, Bridge and Composite patterns and refined them together through peer feedback.

My contribution and the code examples are in the Collaborative Discussion section [Collaborative-Discussion1-unit4]([Advanced-Object-Oriented-Design-and-Programming/Artefacts/Group/Collaborative-Discussion1-unit4.md](https://github.com/Elviix/E-portfolio/blob/main/Advanced-Object-Oriented-Design-and-Programming/Artefacts/Group/Collaborative-Discussion1-unit4.md)). I did not complete the seminar coffee shop exercise separately, because I applied its pattern, the Decorator, directly in my final artefact, where LoggingAccount adds an audit log to BankAccount without modifying it [link]. Discussing the patterns with my peers helped me see the difference in intent between Adapter and Bridge, which look similar in shape but solve different problems.
